# Install a Quest APK from a Chromebook

Once a GLIMP TAG APK has been built in Unity Build Automation:

1. Download the APK file from the cloud build artifact page.
2. Open [SideQuest Web Installer](https://sdq.st/download) in Google Chrome.
3. Connect the Quest 2, Quest 3, or Quest 3S with a USB-C data cable.
4. Put on the headset and approve the **Allow USB debugging** prompt.
5. Select the downloaded APK in the web installer and start installation.
6. On the headset, open Apps, choose the **Unknown Sources** filter, and launch GLIMP TAG.

Developer Mode must be enabled on the headset, and the USB debugging prompt must be accepted. A charge-only USB cable will not work.

This is a browser-based installation route; the desktop Meta Quest Developer Hub is not required for this step. Installation has not been tested with this project yet.
