# GLIMP TAG

GLIMP TAG is an original VR tag game prototype for Meta Quest 2, Quest 3, and Quest 3S.

## Prototype goals
- Gorilla-style arm-push movement
- Original forest arena with climbable routes
- Tag and infection game modes
- Multiplayer-ready architecture

## Important
This repository currently contains starter Unity source, not a finished game or installable APK. It does not copy Gorilla Tag's maps, assets, or branding.

## Chromebook workflow
The source can be edited in GitHub from a Chromebook. A Unity-compatible cloud build service and a configured Unity project are still needed to produce an APK. No local PC or Unity Editor is assumed for this source-editing step.

See `Assets/GLIMP_TAG/SETUP.md` for the next development steps.
